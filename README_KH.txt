VIRA BARCODE SCAN — PWA សម្រាប់ iPhone

នេះជាកម្មវិធី Web App ដែលអាច Add to Home Screen ដើម្បីបើកដូច App លើ iPhone។

ដាក់ឱ្យប្រើ
1. Extract ZIP។
2. Upload ឯកសារទាំងអស់ (រក្សា folder icons) ទៅ HTTPS hosting។ ឧទាហរណ៍ static hosting ដែលផ្ដល់ HTTPS។
3. បើក URL តាម Safari លើ iPhone។
4. ចុច Share → Add to Home Screen → Add។
5. បើក VIRA SCAN ពី Home Screen។
6. បញ្ចូល Barcode, ឈ្មោះ និងតម្លៃទំនិញ រួច Save Product។
7. ចុច បើកកាមេរ៉ាស្កេន ហើយ Allow Camera។

ចំណាំបច្ចេកទេស
- ត្រូវការ HTTPS សម្រាប់ Camera និង Service Worker។
- Scanner module ZXing ត្រូវបានទាញពី esm.sh ដូច្នេះត្រូវការ Internet នៅពេលផ្ទុក module ដំបូង/បើក Scanner។
- បញ្ជីទំនិញ និងការស្កេនរក្សាទុកក្នុង localStorage នៅលើ iPhone នេះ។ មិនមាន Cloud Sync ទៅឧបករណ៍ផ្សេងទេ។
- សូម Export CSV ជាប្រចាំ។ ការលុប Website Data ឬលុប App អាចធ្វើឱ្យបាត់ទិន្នន័យ។
- ត្រូវសាកល្បងលើ iPhone ពិត និង Barcode ពិតមុនប្រើការងារប្រចាំថ្ងៃ។
